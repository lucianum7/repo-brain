# Repo Brain development map

This repository implements an offline-first persistent memory tool for coding agents.

<!-- repo-brain:start -->
For non-trivial changes, run `repo-brain scan`, query `repo-brain context`, read current files with `repo-brain read`, and refresh memory after edits. Memory guides discovery; current source code determines truth.
<!-- repo-brain:end -->

Run `pytest` and `python -m build` before publishing changes. Keep SQLite schema changes migration-safe and never store source secrets.
