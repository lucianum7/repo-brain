# Repo Brain

Run `repo-brain status` and `repo-brain scan` before non-trivial work. Query `repo-brain context "<task>"`, read current source with `repo-brain read FILE`, and treat stale analyses as mandatory rereads. After edits, scan, test, and refresh analysis. Memory guides discovery; current source code determines truth.
